# 美研云客户价值模型（RFM + 忠诚 + 活跃）计算规则 v1.0

> 状态：已拍板落地（2026-09-01）
> 数据口径：`txn_order` 中 `status='已收款'` 的订单；金额单位「分」（bigint），展示转元。
> 实现原则：**读时实时计算，不落库建表**（客户 360 打开时由 txn-service 聚合订单即时算出），阈值集中在本文件与后端常量，便于调参复盘。

---

## 一、竞品 / 行业惯例调研摘要

| 来源 | R（最近消费） | F（频次） | M（金额） | 分层方法 |
|---|---|---|---|---|
| 医美私域 RFM 五步法（医美查） | R 越小越活跃 | 周期内到店次数 | 周期内累计消费 | 圈范围→选指标→定分段→设权重→得结果；建议设有效消费起线（如累计>500元） |
| 整形医院客户分层（人人文库） | 战略级近3月 / 价值级近6月 / 培育级近1年 / 唤醒级>1年 | 战略≥3次互动、价值2-3次、培育1-2次 | 高/中/低客单价项目 | 四层：战略 / 价值 / 培育 / 唤醒 |
| 医美生命周期+RFM（华夏医界网） | >50天1分…≤30天5分 | 频次分档 | <1000元1分…>2500元5分 | 五分位打分，R/F/M 与均值比高低 → 八象限 |
| 医美存量运营（RFM精益学堂） | **活跃90天内 / 失活180天未消费 / 沉睡流失超1年** | **年≥4次高频(粉丝)、2-3次复购、≤1次唤醒** | <5万 / 5-20万 / ≥20万（高端机构口径） | 生命周期×价值双轴；月度复核 |
| 经典零售 RFM（CDA） | 五分位 5→1 分 | 五分位 | 五分位 | 555 至尊VIP、155 待唤醒重要客户等八象限 |

**收敛出的行业共识：**
1. **R 活跃线 90 天、沉睡线 180 天、流失线 365 天**（医美项目复购周期 1-6 个月，轻医美 1-3 月）。
2. **F 以近一年消费次数计**：≥4 次为高频/粉丝，2-3 次为复购，≤1 次为新客/待唤醒。
3. **M 高客单价行业**，阈值显著高于零售（轻医美客单数百至数千，抗衰/手术类数千至数万）。
4. 打分用**五分位（5 分最优）**，分层用**八象限（R/F/M 各比高低）+ 中文命名**，并配差异化运营动作。

## 二、美研云自有五维价值模型

五维 = **R 最近消费 + F 消费频次 + M 消费金额 + L 忠诚度 + A 活跃度**。
前三维（R/F/M）按 5 分制打分；忠诚、活跃为辅助判定维度，用于细分八象限与运营策略。

### 2.1 指标定义（统计窗口 = 近 365 天）

| 维度 | 字段 | 定义 | 方向 |
|---|---|---|---|
| **R** 最近消费 | recencyDays | 最近一笔已收款订单距今天数（无订单=空值） | 越小越好 |
| **F** 消费频次 | freq365 | 近 365 天已收款订单数 | 越大越好 |
| **M** 消费金额 | monetary365 | 近 365 天已收款订单金额合计（**元**） | 越大越好 |
| **L** 忠诚度 | tenureMonths / 累计单量 | 会员存续月数 + 历史累计成交订单数 | 越大越好 |
| **A** 活跃度 | orders90 | 近 90 天已收款订单数（≥1 判为活跃） | 越大越好 |

> 说明：R 用「最近一次消费」不受窗口限制（反映是否流失）；F/M 用近 365 天窗口（反映近一年价值），与行业「年消费」口径一致。

### 2.2 打分阈值（5 分制）—— 依据 seed 库 100 客户真实分位数标定

seed 库实测分位数（近 365 天）：F 中位 3 单 / p75 6 单；M 中位 ¥4160 / p75 ¥8448；R 中位 112 天 / p75 212 天；近 90 天 59% 客户无消费。

**R 评分（recencyDays）**

| 分数 | 区间 | 含义 |
|---|---|---|
| 5 | ≤ 30 天 | 当月在消费 |
| 4 | 31–90 天 | 活跃（90 天线内） |
| 3 | 91–180 天 | 临界（开始沉睡） |
| 2 | 181–365 天 | 沉睡 |
| 1 | > 365 天 / 无成交 | 流失 |

**F 评分（freq365，近一年成交订单数）**

| 分数 | 区间 | 含义 |
|---|---|---|
| 5 | ≥ 8 单 | 超高频 |
| 4 | 6–7 单 | 高频（p75 附近） |
| 3 | 4–5 单 | 稳定复购（行业「年≥4次高频」线） |
| 2 | 2–3 单 | 复购（中位区） |
| 1 | ≤ 1 单 | 新客/单次 |

**M 评分（monetary365，近一年消费金额，元）**

| 分数 | 区间 | 含义 |
|---|---|---|
| 5 | ≥ 15000 | 高净值（抗衰/手术类） |
| 4 | 8000–14999 | 高客单（p75 附近） |
| 3 | 4000–7999 | 中客单（中位区） |
| 2 | 1000–3999 | 低客单（轻医美） |
| 1 | < 1000 / 无成交 | 体验客 |

> 阈值设计原则：**3 分线 ≈ 中位数、4 分线 ≈ p75**，保证分数分布呈纺锤形（中间大、两头小），符合客户价值自然分布；M 起线 1000 元对应行业「有效消费起线」惯例，过滤极低价值体验客。

### 2.3 忠诚度（L）辅助判定

| 判定 | 条件 |
|---|---|
| 高忠诚 | 历史累计成交 ≥ 8 单 **或** 会员存续 ≥ 24 个月 |
| 中忠诚 | 累计成交 4–7 单 或 存续 12–23 个月 |
| 低忠诚 | 累计成交 ≤ 3 单 且 存续 < 12 个月 |

### 2.4 活跃度（A）辅助判定

- **活跃**：近 90 天有成交（orders90 ≥ 1）
- **沉默**：近 90 天无成交、近 180 天有成交
- **沉睡**：近 180 天无成交、近 365 天有成交
- **流失**：近 365 天无成交

## 三、八象限价值分层（中文命名 + 运营策略）

以**标准 RFM 二分法**归类：R 分 ≥4 为「近期」、F/M 分 ≥4 为「高」，**未达 4（含 3 分中间态）一律归「低」侧**。三维各高/低，2³=8 类全覆盖、无遗漏。分层名**全中文**，前端直接展示，不外露技术码。

> seed 100 客户实测分布（2026-09-01）：一般挽留 50 / 重要价值 18 / 一般发展 15 / 重要保持 6 / 一般价值 5 / 重要发展 2 / 重要挽留 1，呈合理纺锤—长尾形（塔尖重要价值客户约 18%）。

| 分层 | RFM 特征 | 客户画像 | 运营策略 |
|---|---|---|---|
| **重要价值客户** | R 高、F 高、M 高（均≥4） | 塔尖 VIP，80% 业绩压舱石 | 1+N 专属服务、新品优先、VIP 通道、转介绍奖励 |
| **重要发展客户** | R 高、F 低、M 高 | 高客单但来得少，潜力大 | 项目组合/疗程卡提升到店频次，专属案例推送 |
| **重要保持客户** | R 低、F 高、M 高 | 曾经高频高消，最近没来 | 满意度回访、专属回归礼，防止流失 |
| **重要挽留客户** | R 低、F 低、M 高 | 高价值沉睡/流失 | 主动外呼+免费护理包，调查流失原因，重点挽回 |
| **一般价值客户** | R 高、F 高、M 低 | 常来但客单低（轻医美） | 升单引导：光电+注射联合、跨品类组合 |
| **一般发展客户** | R 高、F 低、M 低 | 新客/体验客，近期来过 | 皮肤检测报告解读、首单复购券、培育习惯 |
| **一般保持客户** | R 低、F 高、M 低 | 曾经常来的低客单客 | 到店礼包+皮肤检测唤醒，维持复购节奏 |
| **一般挽留客户** | R 低、F 低、M 低 | 低价值沉默/流失 | 低成本批量触达（社群/券），不投入重资源 |

**生命周期阶段（辅助标签）**：新客（累计≤1单）→ 活跃 → 沉默 → 沉睡 → 流失，由 R/A 维度直接映射。

## 四、技术实现约定

1. **读时计算、不建表**：客户 360 价值画像 tab 打开时，txn-service 聚合该客户 `txn_order`（已收款）即时计算 R/F/M/L/A，返回 `RfmView`。不新增数据库表、不跑离线任务。
2. **端点**：`GET /api/txn/customer/{customerId}/rfm`（网关前缀 `/api/txn`），与订单/面诊/预约视图同控制器。
3. **金额单位**：订单 amount 为 bigint「分」，M 计算后转「元」返回；前端不再换算。
4. **零英文外露**：分层名、生命周期、维度名全中文；评分是数字。
5. **无订单客户**：R/F/M 均返回 null/0，分层判为「未成交客户」，不展示评分雷达，提示「暂无成交，无法评估价值」。
6. **阈值可调**：阈值常量集中在后端 `RfmCalculator`，调参后改本文件版本号；正式上线后建议用真实生产数据分位数复核一次（当前阈值基于 seed 100 客户标定）。
