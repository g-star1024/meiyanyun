## §4 数据模型设计（JPA 建表＋V46 增量，对齐 V44 体例）

### 4.1 landing_page 表（marketing-service，JPA ddl-auto=update）

| 列 | 类型 | 说明 |
|---|---|---|
| page_id | VARCHAR(24) PK | LP 前缀业务号（BizNoGenerator 现成） |
| name | VARCHAR(64) NOT NULL | 页面名称 |
| template | VARCHAR(16) NOT NULL | NEWBIE/PROJECT/FESTIVAL/MEMBER/BRAND（chk） |
| status | VARCHAR(16) NOT NULL DEFAULT 'DRAFT' | DRAFT/PUBLISHED/OFFLINE（chk；状态机 DRAFT↔PUBLISHED→OFFLINE，OFFLINE 可再发布回 PUBLISHED） |
| headline / subtitle / project | VARCHAR(128)/(128)/(64) | 主标题/副标题/主推项目 |
| form_fields | VARCHAR(256) | JSON 数组（["姓名","手机","意向项目"]） |
| blocks | VARCHAR(1024) | JSON 数组（块序持久化，moveBlock 写回） |
| visits / leads | BIGINT NOT NULL DEFAULT 0 | 指标字段（D4-A：v1 种子/预留，采集 v2） |
| ab_enabled | BOOLEAN NOT NULL DEFAULT FALSE | A/B 开关 |
| variants | VARCHAR(1024) | JSON 数组（A/B 两版 name/visits/leads） |
| created_by | VARCHAR(32) | 操作人 |
| client_token | VARCHAR(64) | 创建幂等令牌（重放返回原单，对齐 V45 uk 先例建唯一索引） |
| created_at / updated_at | TIMESTAMPTZ NOT NULL DEFAULT now() | 审计 |

### 4.2 calendar_node 表

| 列 | 类型 | 说明 |
|---|---|---|
| node_id | VARCHAR(24) PK | ND 前缀 |
| node_date | DATE NOT NULL | 节点日期（mock 用完整日期演示，跨年固定月日留 v2） |
| title | VARCHAR(32) NOT NULL | 节点名 |
| node_type | VARCHAR(16) NOT NULL | member/festival/campaign（chk） |
| description | VARCHAR(128) | 描述 |

索引：`idx_calendar_node_date(node_date)`。

### 4.3 calendar_schedule 表

| 列 | 类型 | 说明 |
|---|---|---|
| schedule_id | VARCHAR(24) PK | SCH 前缀 |
| node_id | VARCHAR(24) NOT NULL | 逻辑引用 calendar_node.node_id（不建物理外键，对齐 V44 惯例） |
| name | VARCHAR(64) NOT NULL | 活动名称 |
| benefit_desc | VARCHAR(256) | 权益组合 |
| coupon_ids | VARCHAR(512) | JSON 数组（真实券模板 ID，关联 m5Coupon 已真） |
| points_reward | INT NOT NULL DEFAULT 0 | 积分奖励（分） |
| start_date / end_date | DATE NOT NULL | 活动起止（chk start<=end 由 Service 校验） |
| channels | VARCHAR(64) | JSON 数组（SMS/WECOM/WECHAT_MP） |
| copy_text | VARCHAR(512) | 推送文案（服务端敏感词拦截） |
| status | VARCHAR(16) NOT NULL DEFAULT 'SCHEDULED' | DRAFT/SCHEDULED/RUNNING/ENDED（chk；创建即 SCHEDULED，RUNNING/ENDED 由 CalendarScheduleJob 按日期日更，抄 ReferralExpireJob 范式） |
| estimated_revenue_cents | BIGINT NOT NULL DEFAULT 0 | **预计营收（分）**——mock estimatedRevenue 为元，适配层 ×100/÷100（铁律 2，对齐 B86 dealAmountCents 先例） |
| store_code | VARCHAR(16) NULL | D2-A：NULL=全连锁场，门店级排期预留 |
| created_by | VARCHAR(32) | 操作人 |
| client_token | VARCHAR(64) | 创建幂等令牌 |
| created_at / updated_at | TIMESTAMPTZ NOT NULL DEFAULT now() | 审计 |

索引：`idx_calendar_schedule_node(node_id)`、`idx_calendar_schedule_status(status)`、`idx_calendar_schedule_dates(start_date,end_date)`。

### 4.4 V46（Flyway，一次性三表＋幂等可重入）

- `CREATE TABLE IF NOT EXISTS` 三表＋chk 约束＋索引＋COMMENT；不建物理外键；迁移后 JPA ddl-auto=update 全 no-op。
- 字典：枚举全部 chk 约束落库；sys_dictionary 按需补（前端 LABEL 常量已自带，v1 不补字典项，对齐「前端 LABEL 自足」现状）。

### 4.5 CalendarScheduleJob（marketing-service，抄 ReferralExpireJob 范式）

- 每日（对齐 MarketingSchedulerConfig 既有调度装配）：`SCHEDULED→RUNNING`（start_date<=today<=end_date）、`RUNNING/SCHEDULED→ENDED`（today>end_date）；幂等可重入，逐条审计。
