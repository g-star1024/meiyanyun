# 页面联动总图 · 跨模块闭环地图

> 配套：本目录 `M1`~`T-G` 各页 ⑦页面联动 的横向汇总。用于评审「SaaS 全链路是否打通」与开发「接口与事件编排」。
> 五大闭环：①交易闭环 ②客户资产闭环 ③业财一体闭环 ④集团管控闭环 ⑤AI 赋能闭环。横切底座贯穿全链路。

---

## 一、交易闭环（M4 为核心，最高频联动）

```
M4-01 预约看板 ──新建──▶ M4-02 预约创建
M4-01 ──到店──▶ M4-04 到店确认 ──▶ M4-05 接待台
M4-05 ──咨询──▶ M4-09 咨询工作台 ──开方──▶ M4-10 项目开方
M4-06 客情登记（过敏）──拦截──▶ M4-10 开方
M4-10 ──生成订单──▶ M4-13 订单确认 ──确认──▶ M4-15 收款收银
M4-09/10 ──疗程──▶ M4-08 疗程进度追踪 ──耗次──▶ M2-01 划扣执行台
M2-01/M4-14 划扣 ──双签──▶ M4-X 双签模态 ──▶ M6-09 划扣明细 + M1-12 审计
M4-15 收银（现金）──双签──▶ M4-X ──▶ M6-02 收支流水 + M6-03 对账
M4-11 术后回访 ──问题──▶ M4-12 投诉风控 ──补偿──▶ M4-X 双签
M4-16 退款/退卡 ──双签──▶ M4-X ──▶ M6-02 + M6-11 卡余额
M4-19 资产转移 ──双签──▶ M4-X ──▶ M6-11 + M3-16 风控
M4-17 电子病历（签名/存证）──▶ M1-12 审计 + M3-06 旅程
M4-03 排队 / M4-07 撞单 ──归属──▶ M3-14 合并 + M6-08 提成
```

**关键接口/事件**：预约变更事件、到店事件、开方订单事件、划扣双签事件（`transaction_id` 幂等）、收银指令事件（单向，不碰资金）、EMR 存证事件。

## 三、业财一体闭环（M6 为核心，红线区）

```
M4-15 收银（指令）──镜像──▶ M6-02 收支流水（T+1，不碰资金）
M6-02 ──对账──▶ M6-03 对账中心（收银/渠道/银行三方，Outbox 幂等）
M6-03 差异 ──重大调平──▶ M4-X 双签 ──▶ M1-12 审计
M6-09 划扣明细 ──源自──▶ M2-01/M4-14
M6-05 分账结算 ──规则──▶ M1-09 加盟分成 + M6-08 提成 ──发放──▶ M4-X 双签
M6-11 卡余额 ──变更──▶ M4-16 退款 / M4-19 转移
M6-10 预收款监管（只读监控）──预警──▶ M2-18 异常 + M1-12
M6-13/14/15 报表 ──并入──▶ M1-11 合并财报 + M1-13 周月报
M6-04 发票 ──对接──▶ T3-04 税控（单向）
金蝶/用友：T3-04 单向镜像 + Outbox + T+1 对账 + transaction_id 幂等（绝不碰资金池）
```

**关键接口**：收付款指令（仅生成，不落地资金）、三方对账事件、分账计算、发票开具指令（单向）、预算拦截（`M6-16`→`T3-01`）。

## 七、联动验收清单（评审用）

- [ ] 交易链：预约→到店→开方→订单→收银→划扣→双签→明细，全程可回溯。
- [ ] 资金链：收银/退款/分账/发票均为**指令+镜像+对账**，无资金落地（红线）。
- [ ] 双签：所有涉钱/药/客诉/资产/报损/现金均经 `M4-X`，无单人提交。
- [ ] 审计：所有敏感写操作均回流 `T1-04`/`M1-12`，append-only。
- [ ] 权限：数据范围统一由 `M1-05`/`T1-03` 收口，跨店隔离。
- [ ] 客户：画像聚合 `M3-01` 汇总 M4/M6，标签 `T2-03` 复用。
- [ ] AI：所有 AI 动作经 `T3-01` 审批/`A1-17` 脱敏/`A1-04` 合规。
- [ ] 隐私：客户级/医疗级字段全站脱敏展示，导出脱敏。
