# M5 营销中心 + M6 数据财务 · 页面详设（7 要素）

> M5 定位：获客-转化-复购营销引擎，与 M3 客户资产、M4 交易联动。M6 定位：业财一体，从流水到报表，守住钱与账。
> M5 已产 1 页（M5-01 营销活动，双端）；M6 已产 1 页（M6-01 业绩报表，双端）。本文件对 M5-01~15 + M6-01~17 全给 7 要素详设。
> **财务红线**：仅镜像+对账（金蝶/用友单向镜像 + Outbox + T+1 三方对账 + `transaction_id` 幂等），**绝不碰资金池**。
