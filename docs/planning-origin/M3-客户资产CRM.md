## M3-01 客户画像（✓ 已产 · 双端）

① **页面结构**：桌面双栏 = 左主「客户身份/等级/标签 + 消费概览 4 KPI」+ 右辅「旅程时间轴 + 跟进任务 + 风险预警」；顶栏（客户搜索 + 切换客户）；平板 = 身份卡 + KPI 卡 + 旅程卡 + 任务卡 + 底部CTA「新建跟进」。

③ **核心功能**：【图表】消费结构；【列表】旅程/任务；【其他】标签查看、预警钻取、新建跟进。

④ **实现方式**：等级用金#FFCB47 徽标；标签用 tint 底（紫#F1ECFF AI 标/蓝#EBF0FF 行为标）；隐私字段脱敏（受 `A1-17`）；画像数据经 `T2-04` + `A1-02`；写 `T1-04`（查看敏感字段留痕）。

⑤ **交互功能**：搜索切客户；标签悬浮释义；旅程节点钻取（→ 订单/病历）；一键新建跟进（→ `M3-07`）；风险点 → 干预建议。

⑥ **达成效果**：顾问一屏掌握客户全貌，跟进有依据。

⑦ **页面联动**：上游=`M4`（交易/订单）、`M4-17 病历`、`M6-11 卡余额`；下游=`M3-07 跟进`、`M4-18 复诊`、`M3-09 流失`；横切=`A1-02 画像引擎`、`A1-03 复购`、`A1-09 流失`。
