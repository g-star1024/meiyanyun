## 〇、设计总原则

1. **单向镜像红线（store 活规格原文）**：Outbox＋T+1 对账，只从本地业务表向外推送镜像，**绝不反向写资金池**。
2. **绝不假装已连通（DESIGN-P5-B57 §0.5 红线承接）**：无真实三方凭证，外呼失败是预期常态——失败如实落 FAILED＋error_msg，CONNECTED 只能由真实探测驱动，**禁止 Math.random() 造成功/造长短款**（mock 三处随机源全摘）。
3. **配置窗口与连接器本体分层**：B57 卡2 已建 external_integration（V34，密钥/URL/开关配置窗口，AES-GCM 单点持钥）——本批建「连接器目录/出站消息/对账批次/调用日志」四表承载运行态，密钥仍由 external_integration 单点持有，连接器仅存 credential_key 引用名，**不复制密钥、不明文落库**。
4. **权限/路由/网关零新增**：`integration:view/create/edit/sync/reconcile` 五码已在 PermissionMatrix 注册并授权（B57 卡2 实证）；`/integrations` 路由与菜单真实存在；新端点挂 org-service `/api/org` 前缀，internal 端点网关对外 404。
5. **前端签名全保留**：store 导出签名（connectors/callLogs/outbox/batches/各 computed/六命令/seed）逐一保留，View template/style 零改动，tabOpts/状态投影由 store 切真适配。

## 二、范围与红线

### 2.1 本批范围（四 tab 切真）
1. **连接器目录**：9 类连接器 CRUD＋状态机（DISCONNECTED/CONNECTED/ERROR 三态落库；SYNCING 为运行瞬时态不落库，前端 pending 集合投影）＋真实测试连接（RestTemplate 短超时探测，结果如实）。
2. **调用日志**：测试连接/同步外呼逐次落库（transaction_id 幂等键 uk(connector_id,transaction_id)）。
3. **Outbox 出站**：同步引擎——txn 已支付订单→连接器镜像消息（uk(connector_id,txn_no) 幂等）→真实外呼→状态机（PENDING/ACK/FAILED→对账后 MATCHED）＋失败重发（仅 FAILED 可重发，幂等）。
4. **T+1 对账批次**：本地口径统计（无三方账单源）——total/matched(=remote_ack)/pending/failed 实算，**long/short 恒 0 如实**（三方账单文件导入解析留 §7 移交）；Job 每日 06:30 Asia/Shanghai 生成昨日批次＋手动触发端点。

### 2.2 不范围（红线登记，不勾销）
- 支付出站真实对接（微信/支付宝/银联商户入网）、广告 OAuth/spend 拉单/ROI 联调（04 L55 保留）、通知厂商签名/模板审核/回执（04 L67 保留）、医保/税控/ERP 真实协议对接——均「真实三方接入远期」，本批交付的是**链路本体建成＋诚实降级**。
- MQ broker（RocketMQ/Kafka）基建引入——DomainEventPublisher Mq 实现仍 Logging，登记 §7。
- CDC（Debezium/Canal）——数据仓库 CDC 采集留 T3 后续批或数据中台专项二期，登记 §7。
- 三方账单文件导入/解析（长短款真源）——登记 §7。

## 三、数据模型（V70~V73，org-service，CREATE TABLE IF NOT EXISTS 双库可重入）

### V70 integration_connector（连接器目录）
| 列 | 型 | 约束 |
|---|---|---|
| id | BIGSERIAL | PK |
| code | VARCHAR(32) | UNIQUE NOT NULL（CONN-WX/CONN-ALI/CONN-UMS/CONN-SHYB/CONN-WECOM/CONN-BW/CONN-OCEAN/CONN-KD/CONN-YY 种子九码） |
| type | VARCHAR(16) | chk PAYMENT/INSURANCE/WECOM/TAX/ADS/KINGDEE/YONYOU |
| name | VARCHAR(64) | NOT NULL |
| endpoint | VARCHAR(256) | NOT NULL（保存校验 https://；http 需 force_insecure=true 二次确认，照 B57 卡2 美团采纳项） |
| credential_key | VARCHAR(128) | NULL（引用名，掩码回显 前4\*\*\*\*后4，密钥本体在 external_integration 单点持钥） |
| status | VARCHAR(16) | chk CONNECTED/DISCONNECTED/ERROR，默认 DISCONNECTED |
| last_sync_at / last_error | TIMESTAMPTZ / VARCHAR(256) | NULL |
| created_at / updated_at | TIMESTAMPTZ | 默认 now() |

### V71 integration_call_log（调用日志）
id BIGSERIAL PK／connector_id BIGINT NOT NULL FK→integration_connector(id)／transaction_id VARCHAR(64) NOT NULL／direction VARCHAR(4) chk OUT/IN 默认 OUT／method VARCHAR(8)／endpoint VARCHAR(256)／status_code INT／latency_ms INT／status VARCHAR(8) chk SENT/ACK/FAIL／error_msg VARCHAR(256) NULL／request_at TIMESTAMPTZ 默认 now()；**uk(connector_id, transaction_id)**；索引 (connector_id, request_at DESC)。

### V72 integration_outbox（出站消息）
id BIGSERIAL PK／outbox_no VARCHAR(40) UNIQUE（OB-yyyyMMdd-seq，库内 maxSeqOfDay 照 B95 D7 先例）／connector_id BIGINT NOT NULL FK／biz_type VARCHAR(16) chk ORDER_PAY/REFUND/INVOICE/VOUCHER/CONTACT/AD_CLICK／txn_no VARCHAR(64) NOT NULL／amount NUMERIC(14,2) NULL／local_sent BOOLEAN 默认 true／remote_ack BOOLEAN 默认 false／reconciled BOOLEAN 默认 false／status VARCHAR(8) chk PENDING/ACK/FAILED/MATCHED/LONG/SHORT 默认 PENDING／error_msg VARCHAR(256) NULL／occurred_at TIMESTAMPTZ 默认 now()／reconciled_at NULL；**uk(connector_id, txn_no) 幂等锚**；索引 (status, reconciled)。

### V73 integration_reconcile_batch（T+1 对账批次）
id BIGSERIAL PK／batch_no VARCHAR(40) UNIQUE（REC-yyyyMMdd-seq）／connector_id BIGINT NOT NULL DEFAULT 0（0=全部连接器，避开 NULL 不参与 uk）／biz_date DATE NOT NULL／total_count/matched_count/pending_count/long_count/short_count/failed_count INT 六计数默认 0／total_amount/diff_amount NUMERIC(14,2) 默认 0／status VARCHAR(8) chk RUNNING/DONE/FAILED／started_at/finished_at TIMESTAMPTZ；**uk(connector_id, biz_date) 幂等**。
