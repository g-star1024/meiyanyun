## 一、项目现状盘点

### 1.1 系统形态

美研云 HIS 是医美连锁 B 端门店中台（SaaS + 私有化双形态），monorepo 结构：

| 层    | 技术栈                                     | 说明                                               |
| ---- | --------------------------------------- | ------------------------------------------------ |
| 前端   | Vue 3 + TS + Vite + Pinia，原生 CSS 变量     | 约 156 页面、107 Pinia store；10 个页面已接真实 API，其余为 mock |
| 网关   | Go + 国密 TLS（SM2 双证书）                    | 正式 8443 / seed 18443；路由按 `/api/<域>` 前缀硬编码转发      |
| 后端   | Java 17 + Spring Boot 3.2.5 + Maven 多模块 | 7 微服务共单库，端口 8082–8088                            |
| 基础设施 | PG15 / Redis7 / RocketMQ / MinIO / ES   | 宿主端口 5433 / 6380 / 9000-9001 / 9200              |

### 1.2 双栈运行（24 容器全部 healthy，2026-09-01 实证）

| 栈                       | 数据库                           | 客户数据      | 访问入口                                | 用途        |
| ----------------------- | ----------------------------- | --------- | ----------------------------------- | --------- |
| 正式栈 meiyun-\*           | meiyun\_core（M00x 客户）         | 少而精       | <http://127.0.0.1:8080> / 网关 8443   | 主线开发验证    |

## 四、统一验收标准（DoD，摘自 meiyun-dev-rules §7）

每个工作项「完成」必须同时满足：

1. **后端** `mvn package` 全模块通过；前端 `vue-tsc` 0 error、`pnpm build` 通过
2. **写链路** curl 验证全异常路径：参数校验 400、幂等冲突 409、无权限 403，错误信息全中文、零技术码外露
3. **数据对账**：写操作后 SQL 核对主表/审计表/库存/金额，审计 jsonb 记录全动作
4. **前端** 双端（正式 8080 / seed 18080）截图留存，真实 API、无 mock 残留、axios 取 `.data`
5. **隔离核验**：双栈互不串库、独立网络、容器名/端口不冲突
6. **同类全站扫**：改一个范式（如金额单位、权限指令）须 grep 全站同类点一并修正
7. **基线恢复**：验证后 seed 栈可 `reset-seed-db.sh` 复原，正式栈数据不被污染
8. **文档同步**：HANDOFF / DEV-PROGRESS / 看板状态三处更新

## 五、铁律红线（违反即返工）

- **API 路径**：一律 `/api/<域>`，**禁用** **`/api/v1`**（网关硬编码前缀，v1 必 404）；网关/控制器/前端三处一致

- **金额单位**：txn 域 bigint 存「分」；customer 域 decimal 存「元」——跨域换算在服务边界完成

- **写链路四件套**：参数校验 → 幂等（409）→ 全动作审计（jsonb）→ 中文错误信息

- **多栈隔离四要素**：项目名 / 容器名 / 端口 / **独立 Docker 网络**，缺一必串库

- **表结构分层**：Flyway 管 `sys_*` 系统表；JPA `ddl-auto:update` 管业务表，不混用

- **服务间**：RestTemplate（3s/5s 超时 + 降级 + 批量名解析 Resolver），**禁止跨域直读他服务表**

- **缓存**：使用缓存的服务必须显式 `@EnableCaching`；HikariCP 池上限 5

- **业务单号**：当日最大序号 +1 生成，**禁用 AtomicLong**（重启/多实例会重号）

- **前端 CSS**：禁裸值、禁 `--sp-*`（未定义变量静默失效，间距用 `--s-*`）

- **命令行**：进程持稳必须 run\_in\_background + wait；curl 加 `--noproxy '*'`，HTTPS 加 `-sk`

## 七、协作机制

1. **开发前**：加载 `meiyun-dev-rules` skill；改 `.vue` 先加载 `design-fidelity` skill；新会话先读 HANDOFF + DEVELOPMENT\_PLAN
2. **跨边界决策**（数据口径/模型/范围）：先与用户拍板再动手，不自行扩大范围
3. **进度跟踪**：`docs/meiyun-delivery-board.html` 看板（30 工作项，状态/优先级/业务域可筛选）
4. **持续集成**：提交即触发 CI（后端测试 / 前端构建 / 网关 vet），红线不过不合并
5. **进度留痕**：每完成一项更新看板状态 + DEV-PROGRESS 日志 + 必要时 HANDOFF
