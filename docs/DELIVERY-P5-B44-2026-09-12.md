## 1. 背景与目标

B43 打通真实大模型调用出口后，出站链路缺三道治理闸：

1. **配额**：只有配置面，没有任何调用频次/额度约束，误调用或异常脚本可无限消耗付费 token；
2. **合规/安全**：用户提示词直接拼进 prompt 出站，既无医美行业违禁内容过滤，也无 prompt injection（越权套取系统提示词、诱导越权）防护；
3. **可观测告警**：网关 KPI「活跃告警」在 B43 仍是硬编码 0，P99/错误率/额度水位越线没有任何感知。

B44 目标（ROADMAP §④ B44 验收口径）：ai_quota 二期表（按功能/模型/全局的日/月额度与已用计量）+ 调用前配额扣减与超限中文拒绝 + 敏感词/越权提示词过滤 + 监控告警（失败率/延迟/额度阈值）+ A1Admin 配额管理 UI。

### 2.2 配额：三级校验 + upsert + 审计

[QuotaService.java](file:///Users/huluobo/WorkBuddy/2026-08-15-23-51-02/meiyun-platform/backend/ai-service/src/main/java/com/meiyun/ai/quota/QuotaService.java)：

- `@PostConstruct seedDefaults()`：启动幂等播种 GLOBAL（target=`*`）+ 六功能 FEATURE 共 7 行默认「不限/启用」，MODEL 维度不预建（list 返回虚拟默认视图，首次保存才建行）；
- `check(featureCode, modelCode)`：出站前按 **FEATURE → MODEL → GLOBAL** 依次校验，任一**启用**维度窗内 count ≥ 限额即抛 **429** 中文（「『客户画像』今日调用额度已用尽（已用 0/0 次），请次日再试或联系管理员调整配额」）；维度未建/停用/限额 NULL 一律放行；
- `list()`：六功能 + 所有已登记模型（无 DB 行返回 quotaId=null 的默认「不限」视图）+ 全局兜底，实时拼日/月已用量；
- `save()`：scope 白名单校验、target 非空、额度非负；upsert + **全字段相等 changed=false 幂等短路**（不 save/不刷 updated_at/不写审计）；changed 才落库并写 **AI_QUOTA** 审计（payload 合法 JSON，null 额度序列化为空串）；
- `maxWatermarkPercent()`：供告警用，遍历启用维度取日/月水位最高百分比（不限额度不参与，四舍五入到 0.1）。

[QuotaController.java](file:///Users/huluobo/WorkBuddy/2026-08-15-23-51-02/meiyun-platform/backend/ai-service/src/main/java/com/meiyun/ai/quota/QuotaController.java)：`GET /api/ai/quotas`（类级 aiAdmin:view）、`POST /api/ai/quotas/{scope}/save?target=`（aiAdmin:edit）。

### 2.4 拦截链接入顺序（关键）

[FeatureInvokeService.java](file:///Users/huluobo/WorkBuddy/2026-08-15-23-51-02/meiyun-platform/backend/ai-service/src/main/java/com/meiyun/ai/feature/FeatureInvokeService.java) 在 Key 解密之后、prompt 组装/出站之前依次插入：

```
灰度/角色校验(403) → 供应商/模型/Key 校验与解密
   → sensitiveWordService.screen(input)   // 400，违禁/越权
   → quotaService.check(feature, model)   // 429，超限
   → 组装 prompt → LlmClient 出站
```

**被 400/429 拦截的请求不写 ai_invoke_log、不占调用量、不产生费用**——拦截是纯前置闸，用量真相不被失败/拒绝请求污染。

## 6. 观察项与 Backlog

- **P99 阈值 200ms 对推理模型偏严**：ark-code-latest 单次推理秒级~分钟级，常态即越线。当前阈值按传统网关口径播种，后续应按功能/模型分级设阈或改用统计基线（同环比），登记治理；
- **MODEL 配额按 modelCode 聚合**：跨供应商同 modelCode 的用量会计入同一模型维度（现网 modelCode 唯一，暂无歧义），多供应商阶段如需按供应商拆分别再细化维度；
- **告警仅实时评估、无持久化事件与通知下发**：status/currentValue 每次请求现算，未落告警事件表、未真正发站内信。通知通道（站内信/短信/邮件）与告警事件持久化、告警静默/升级留后续；
- **敏感词为小写 contains 朴素匹配**：暂无拼音/拆字/形近字绕过与正则词表，INJECTION 库持续运营补充；
