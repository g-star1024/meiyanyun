## 1. 三卡方案要点

### 1.1 卡① 排队智能候补（arrival_waitlist 新域，txn-service）

| 能力 | 真实端点 / 规则 | 状态 |
| --- | --- | --- |
| 候补登记 | `POST /api/txn/waitlist`，waitlist:create；body{customerName,phone,project,expectDate?,note?,customerId?}，姓名/手机/项目 @NotBlank；门店取 JWT 当前本店；手机号反查客户目录自动锚定会员（命中→customer_id，未中→散客快照 customer_id 空、手机号掩码出域）；同客户或同掩码手机号已有活跃候补（WAITING/NOTIFIED）→ 409 防重 | **新建** |
| 取消候补 | `POST /api/txn/waitlist/{wlNo}/cancel`：WAITING/NOTIFIED→CANCELLED；终态（CANCELLED/FULFILLED）再操作 → 400 中文 | **新建** |
| 到场转正式号 | `POST /api/txn/waitlist/{wlNo}/fulfill` body{channel}：须 customer_id 已锚定（散客 → 400「请先建档」）；channel 仅 WALK_IN/REFERRAL/MARKETING（APPOINTMENT 渠道走预约勾连链，fulfill 传 APPOINTMENT → 400）；同事务 arrivalService.create 建正式 AH（queue_no 续号）并回写 wl.ah_no；WAITING/NOTIFIED→FULFILLED；重复 fulfill → 400 并带回 ahNo | **新建** |
| 自动递补 | waitlistService.promoteNext(storeCode, operator=system)：取本店首位 WAITING（createdAt asc FIFO）→ NOTIFIED + notified_at，给本店 STORE_MGR 发站内信（idemKey=`WL:<wlNo>:<staffId>` 幂等，NotifyPreference SYSTEM 免打扰者跳过）；无待通知目标则不置 NOTIFIED、返回 false | **新建** |
| 候补队列 | `GET /api/txn/waitlist?status=&storeCode=`，waitlist:view；DataScope 门店域强制注入，默认本店按 createdAt asc | **新建** |

- 候补状态机：WAITING →（号源释放递补）NOTIFIED →（到场）FULFILLED；WAITING/NOTIFIED →（取消）CANCELLED；FULFILLED/CANCELLED 终态。
- 触发点：手工释放与系统超时释放的**同事务内**调用 promoteNext（见 1.2），保证「号源一空出就递补」，无后台额外调度。

### 1.2 卡② 候诊超时自动释放号源（ArrivalAutoReleaseJob + 手工释放）

- 手工释放（B28 仅前端「释放中」占位，本批接真）：`POST /api/txn/arrivals/{ahNo}/release`，reception:edit；仅 WAITING 可释放（否则 400「仅候诊中的登记可释放号源，当前状态: X」）；置 LEFT + left_at；**同事务 promoteNext**；audit ARRIVAL/RELEASE reason=MANUAL。
- 自动释放 Job：`ArrivalAutoReleaseJob` `@Scheduled(fixedDelay=60_000, initialDelay=20_000)`；
  - cutoff = now −（waitingTimeoutMin 30 + releaseGraceMin 10）分钟（阈值与宽限走参数配置，/queue 顶部提示条展示「30 分钟 · 超时 10 分钟宽限后自动释放号源」）；
  - 扫本店全量中 arrived_at 早于 cutoff 的 WAITING 单，最早 50 条一批；releaseTimeoutBySystem 内**重载状态**防与手工释放竞争重入（reason=TIMEOUT）；同事务 promoteNext；单条异常 try/catch 不中断整轮；
  - 总开关 `meiyun.queue.auto-release-enabled`（默认开）；日志模板「候诊超时自动释放本轮完成 候选={} 释放={} 跳过={} cutoff={}」。

### 1.3 卡③ 到店核销 ↔ 预约 / writeoff 自动勾连（checkin 既有登记链扩写）

- 触发：`POST /api/txn/checkin/records` method=APPOINTMENT，手机号命中**当日未取消预约**时，同一事务内：
  1. checkin_record 落 ci_no 并回填 **appt_no**；
  2. 生成 **wd_no**（writeoff_desk_task，status=PENDING）待划扣执行台承接；
  3. 预约置「已到店」；
  4. 自动建 arrival（channel=APPOINTMENT、appt_no 回填、queue_no 本店当日续号）；
  5. timeline 追加系统条「已自动勾连预约 AP…，并生成待划扣任务 WD…（预约置已到店）」。
- 读模型：checkin 列表/详情透出 apptNo/wdNo；CheckinView detail__grid 新增「勾连预约单」field，渲染 `AP… · 划扣任务 WD…`。
- 幂等：当日同手机号已有 PENDING 单 → 返回既有单（沿用 B28 防双到店），不重复勾连/建号。
- 未命中当日预约的 APPOINTMENT 登记维持 B28 行为（前台人工异常码 NO_APPOINTMENT），本卡只做命中后的自动勾连，不改动异常路径。

## 2. 后端设计

### 2.1 新表 1 张（JPA ddl-auto=update 自动建）

- **arrival_waitlist**：wl_no PK varchar(24)（WL+yyyyMMdd+-+6 位查库序号）、store_code、customer_id（散客可空）、customer_name not null、phone（掩码出域/明文落库，与 checkin 同口径）、project、expect_date（可空）、note、status（WAITING/NOTIFIED/FULFILLED/CANCELLED）、ah_no（fulfill 回写）、operator、notified_at、created_at、timeline text（JSON 数组文本，登记/递补/到场/取消同事务追加）。

### 2.2 端点清单（全部经既有网关路由，网关零改动）

| 方法/路径 | 权限 | 说明 |
| --- | --- | --- |

### 2.3 审计（append-only，payload 手工拼合法 JSON）

- APPT：CHECK_IN（预约置已到店）；WDESK：AUTO_CREATE；ARRIVAL：AUTO_CREATE（卡③同事务三连）；CHECKIN：REGISTER/CONFIRM。

## 4. 疑点清单 × 自主决策

| # | 疑点 | 决策 |
| --- | --- | --- |
| 1 | 候补散客如何处理 | 沿用 B28 口径：不私建客户；手机号查无会员落 customer_id 空的快照候补（掩码出域）；但 fulfill 强制要求已锚定（散客须先建档），避免无主正式到店号 |
| 2 | 候补防重粒度 | 同 customer_id 有活跃候补（WAITING/NOTIFIED）→ 409；散客按同掩码手机号判重；FULFILLED/CANCELLED 终态不拦截重新登记 |
| 3 | 递补 FIFO 与通知目标 | createdAt asc 取首位 WAITING；通知给本店 STORE_MGR（李店长 E005），逐人 idemKey 幂等、SYSTEM 免打扰跳过；通知目标为 0 时不把候补置 NOTIFIED（保持 WAITING 等下轮） |
| 4 | 递补触发时机 | 不另起调度；手工 release 与 Job 超时 releaseInternal 同事务内调 promoteNext，号源空出与递补原子可见 |
| 5 | 超时阈值/宽限口径 | waitingTimeoutMin=30 + releaseGraceMin=10，cutoff=now−40min；参数可配（设置中心后端化为既有 Backlog），总开关 meiyun.queue.auto-release-enabled |
| 6 | Job 与手工释放竞争 | releaseTimeoutBySystem 释放前重载单行状态，非 WAITING 则跳过（skip 计数），避免对已手工释放单重复释放/重复递补 |
| 7 | fulfill 渠道白名单 | WALK_IN/REFERRAL/MARKETING；APPOINTMENT 渠道必须走卡③预约勾连链（checkin），fulfill 传 APPOINTMENT → 400「非法到店渠道」，防候补单绕过预约校验 |
| 8 | 卡③未命中预约 | 维持 B28 人工 NO_APPOINTMENT 异常路径，本卡只在「手机号命中当日未取消预约」时自动勾连，不扩大自动比对面 |
| 9 | 卡③防双到店 | 当日同手机号 PENDING 单幂等返回既有 ci_no（沿用 B28），同事务四连写（ci/wd/appt/arrival）只发生一次 |
| 10 | 单号回退 | 单号均应用层查库 max+1，冒烟清理删行不回退序列（无独立号段表），下一号自然跳过，与 B25–B28 同口径 |
| 11 | 第三卡样式 | 复用候诊卡现有类 + 少量追加 scoped 类（交接定案允许的全批唯一例外），不动公共组件与全局样式 |
| 12 | 截图取证落盘 | 沿 B28 限制，take_screenshot filePath 受 workspace root 约束无法落盘，以**内联图片附件**取证，文档不引用截图路径 |
