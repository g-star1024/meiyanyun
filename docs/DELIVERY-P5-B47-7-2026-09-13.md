## 1. 背景与目标

A1 AI 中心第 7 张切真卡。原 A1KnowledgeView 为纯 mock 页（假知识条目/假统计/假引用），本卡将其整页接到真实持久化：知识条目三类（project 项目知识 / script 方案话术 / compliance 法规合规）的录入、编辑、浏览、检索、引用溯源与反馈全链路落 PG。

三条**诚实口径**（V28 注释、Service javadoc、页面注脚三处同文）：

1. 「向量化/索引」当前为 **PG ILIKE 词法检索可用状态**（标题/标签/正文加权召回），`index_status=INDEXED` 即进入可检索索引；语义向量（EMBEDDING 模型 + pgvector）依赖多能力模型接入，属远期 Backlog，不伪造向量维度与相似度。
2. 「引用」只来自本页真实检索事件（`ai_knowledge_citation` append-only，当前唯一来源 `manual_search`）；话术/客服/内容生成的 RAG 自动检索联动为远期，枚举已预留 `scripts/chatbot/content` 但不编造跨模块流水。
3. 「引用准确率」不写死，由 citation 的 useful 反馈真实计算，无反馈返回 null，页面显「—」。

知识库是**管理/检索面而非 AI invoke 功能**：不接 FeatureCatalog、不走模型绑定/灰度/配额/计费，写动作经 AI_KNOWLEDGE 审计链留痕。

### 2.4 KnowledgeService（365 行，10 个公有方法 + 6 个 record 契约）

- **stats 九键**：totalDocs/indexedCount/pendingCount/failedCount/indexedPct（空库归零，非 null）/totalRefs/todaySearches（**北京时间日界**）/feedbackTotal/**usefulRatePct（无反馈为 null，页面显「—」）**。
- **search（@Transactional）**：必须登录（未登录 401 中文）；每条命中写一条 manual_search citation（带经办三列）并 `refs_count+1` 同事务回写；返回 citationId/docId/title/category/tags/snippet（正文截 120 字加省略号）/rank/refsCount。浏览（list）不产生任何引用。
- **create 刻意不加方法级事务**：仓储 save 自行提交后新持久化上下文 `findById` 回读 PG now() 时间戳（B47 卡5 同款踩坑前置规避）；source 空白归一「人工录入」；强制 INDEXED + 词法 index_note；落 AI_KNOWLEDGE/CREATE 审计（payload title/category/indexStatus）。
- **update**：四件套校验（标题非空 ≤200、分类白名单、正文非空 ≤8000、标签 ≤500、来源 ≤200，全部中文 400）；编辑后重新置 INDEXED（同步 ILIKE 无异步管道）；落 UPDATE 审计。
- **reindex（@Transactional）**：FAILED/PENDING→INDEXED 才落 REINDEX 审计（payload from/to）；已是 INDEXED 的重放**幂等零审计**。
- **feedback**：citation 不存在 404；cmd.useful 为 null → 400「反馈 useful 不能为空」；**仅状态翻转才落 FEEDBACK 审计**（payload docId/useful），同态重放幂等零落审计。

## 5. 真验过程发现与修复

1. **recall() 原生 SQL 参数类型**：原生 SQL 中字符串拼接参数未 cast 时 PG 推断类型不一致导致召回查询失败，5 处统一 `cast(:keyword as text)` 修复。
2. **list 非法 category 口径**：非空但不在白名单的 category 此前行为不明确，统一走 normalizeCategory 抛中文 400，与 create/update 校验口径一致。
3. **前端列表列 key 错配（真实渲染缺陷）**：CTable 列定义误用 `vector`/`refs` 等旧 mock 字段名，致索引列插槽取不到值、**INDEXED 行此前恒显「索引失败」**；改为 `indexStatus`/`refsCount` 后三态正确。
4. **ai.ts 契约修正**：`feedbackCitation` 返回类型对齐后端为 `Promise<KnowledgeCitation>`（反馈后需拿最新 useful 原地替换），删除未使用的 KnowledgeActionResult。
5. **fat-jar 陈旧致 V28 未迁移（B38 踩坑复现）**：首次只 `mvn compile` 就重建镜像，容器内仍是旧 jar、V28 不执行；按既有纪律改 `mvn package` 重打 fat-jar 后重建，V28 正常 applied。
