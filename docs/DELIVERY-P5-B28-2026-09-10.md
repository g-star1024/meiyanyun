## 2. 后端设计

### 2.1 新表 2 张 + 加列 9 个

- **checkin_record**：ci_no PK varchar(24)（CI+yyyyMMdd+-+6 位查库序号，CheckinNoGenerator 本店当日窗口 max+1）、store_code、customer_id（散客可空）、customer_name not null、phone not null（掩码出域、明文落库）、project、method（SCAN/APPOINTMENT/WALKIN）、status（PENDING/DONE/EXCEPTION）、exception_reason（空串占位）、note、operator、arrived_at/checked_at、created_at、timeline varchar(8192) not null（JSON 数组文本）。
- **triage_reassign**：见 1.3。
- **customer 加 9 列**：见 1.2（JPA update 自动加，无 Flyway；旧行新列全 NULL，回显自然稀疏）。

### 2.2 端点清单（全部经既有网关路由，网关零改动）

| 方法/路径 | 权限 | 说明 |
| --- | --- | --- |
| GET /api/txn/checkin/records | checkin:view | 到店队列，date 默认今日，DataScope 门店域强制注入，显式他店码 → 404 |
| POST /api/txn/checkin/records | checkin:create | 登记；四元 @NotBlank + 方式白名单；当日同手机号 PENDING 单幂等返回既有单 |
| POST /api/txn/checkin/records/{ciNo}/confirm | checkin:create | PENDING→DONE |
| POST /api/txn/checkin/records/{ciNo}/exception | checkin:create | →EXCEPTION（reason 白名单 + note 长度） |
| POST /api/txn/checkin/records/{ciNo}/reset | checkin:create | EXCEPTION→PENDING |
| GET /api/customer/internal/customers/by-phone | X-Internal-Token（internal:customer-directory） | 服务间目录查询：本店→公海→404，DTO 不含手机号 |
| POST /api/txn/arrivals/{ahNo}/reassign（既有，扩写历史） | reception:edit | 同事务追加 triage_reassign 行 |

- 越权统一 404（无权限访问端点 403 由 RequirePerm 拦截器既有逻辑）；非法状态机/白名单不符 → 400 中文。
- 服务间走 HTTP 不跨库直读（CustomerDirectoryClient 带 X-Internal-Token，沿用 B22/B24 内部投影纪律）。

### 2.3 审计（bizType=CHECKIN，append-only）

- REGISTER / CONFIRM / EXCEPTION / RESET 四动作，payload 手工拼合法 JSON（esc 转义）：
  - REGISTER：{store,method,project,anchored,customer:"M014"|"SNAPSHOT",customerName?}——锚定会员记 customerId，散客记 "SNAPSHOT"；**两态均不含手机明文**。
  - CONFIRM：{status:"DONE",customer}；EXCEPTION：{reason,note}；RESET：{}。
- AuditRecorder 失败仅 log 不阻业务（沿既有设计）；本批审计 id **301–313 共 13 行**（含 CUSTOMER/ARRIVAL/PLAN 伴随动作，见 §5.6）。

| # | 疑点 | 决策 |
| --- | --- | --- |
| 1 | 散客（手机号查无会员）如何登记 | 不私建客户；customer_id 留空，姓名/手机落登记快照，审计 customer="SNAPSHOT"；后续同号会员锚定不影响已存在快照单 |

| 7 | 异常码 | NOT_SELF / ALREADY_DONE / NO_APPOINTMENT / INFO_MISMATCH 四码白名单，EXCEPTION_TEXT 中文化；DONE 单不可标异常、EXCEPTION 单不可直接确认 |
