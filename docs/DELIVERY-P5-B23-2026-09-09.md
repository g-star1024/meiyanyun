## 二、接口与状态契约

### 2.1 积分商城（base path：`/api/customer/mall`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/products` | 商品列表，可按中文状态过滤 |
| POST | `/product` | 新建商品 |
| PUT | `/product/{id}` | 编辑商品 |
| POST | `/product/{id}/toggle` | 上架 / 下架切换，同态短路 |
| POST | `/product/{id}/adjust` | 调整库存 / 积分价 |
| GET | `/rule` | 查询积分规则 |
| PUT | `/rule` | 保存积分规则 |
| GET | `/exchanges` | 兑换单列表 |
| GET | `/exchanges/my` | 当前客户兑换单 |
| POST | `/exchange` | 幂等下单，初始状态「待审核」 |
| POST | `/exchange/{id}/review` | 双签审核通过 / 拒绝 |
| POST | `/exchange/{id}/fulfill` | 履约发放，已发放幂等 |

中文契约：

- 商品状态：已上架 / 已下架。
- 商品类型：项目 / 实物 / 优惠券 / 服务。
- 兑换单状态：待审核 / 已通过 / 已拒绝 / 已发放。
- 商品 / 兑换单号按日期前缀 + 当日最大序号生成，不用内存自增。
- 审核通过时同事务完成扣积分、扣库存、累加 `redeemed_count`、更新兑换单状态。

### 2.2 积分账户（base path：`/api/customer`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/points-pool` | 积分池真实读模型 |
| GET | `/{id}/points` | 客户积分流水分页 |
| POST | `/{id}/points` | 人工调分 |

人工调分请求体：

```json
{
  "changeAmt": 100,
  "reason": "活动补偿",
  "clientToken": "uuid"
}
```

硬规则：

- `changeAmt` 必须为非零正负整数，0 不允许提交。
- `reason` 必填，最多 64 字。
- 调后余额必须 `>= 0`。
- `points_ledger.client_token` 上有部分唯一索引：`UNIQUE(client_token) WHERE client_token IS NOT NULL`。
- 同一 token 重放返回原流水，不重复加减分、不重复审计。
- 后端落 `balance_after >= 0` CHECK；前端在提交前实时预览并禁用负余额提交。

### 2.3 客户标签（base path：`/api/customer`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/tags` | 全部标签 |
| GET | `/tags/overview` | 标签覆盖汇总 |
| POST | `/tags` | 新建标签 |
| PUT | `/tags/{tagId}` | 编辑标签 |
| DELETE | `/tags/{tagId}` | 删除标签定义并级联解绑 |
| GET | `/{id}/tags` | 客户已打标签 |
| POST | `/{id}/tags/{tagId}` | 客户打标，重复 409 |
| DELETE | `/{id}/tags/{tagId}` | 客户删标 |
| GET | `/customer?tagId=...` | 客户列表按标签 exists 过滤 |

五分类中文枚举：消费 / 肤质 / 行为 / 价值 / 医疗。标签名全局唯一；删除定义返回 `{deleted, unassignedCustomers}`。

### 2.4 会员等级（base path：`/api/customer`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/member-levels` | 五档等级 + 实时人数 / 占比 / 折扣 |
| PUT | `/member-levels/{level}` | 编辑阈值与权益 |
| POST | `/member-levels/auto-upgrade` | 执行自动升级，只升不降 |
| GET | `/level-rule` | 查询单行等级规则 |
| PUT | `/level-rule` | 保存等级规则 |
| POST | `/{id}/level` | 手工调级 |

等级与阈值：

| 等级 | tier | 自动升级阈值 | 折扣 |
|---|---|---:|---:|
| 普通 | NORMAL | 0 | 1.00 |
| 银卡 | SILVER | 5,000 | 0.95 |
| 金卡 | GOLD | 20,000 | 0.90 |
| 钻石 | DIAMOND | 50,000 | 0.85 |
| 黑卡 | BLACK | 100,000 | 0.80 |

规则字段包含计算周期、降级保护月、自动升级开关、积分倍率。自动升级按积分阈值把符合条件的客户升至对应等级；手工调级同值短路，不重复审计。
