// marketing-service 新增 MarketingWeeklySub.java
@Entity @Table(name = "marketing_weekly_sub", uniqueConstraints =
    @UniqueConstraint(name = "uk_mkt_weekly_sub_staff", columnNames = "staff_no"))
public class MarketingWeeklySub {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY) private Long id;
    @Column(name = "staff_no", nullable = false, length = 32) private String staffNo;
    @Column(nullable = false) private boolean enabled;
    @Column(name = "last_sent_week", length = 8) private String lastSentWeek; // 如 2026-W39
    @Column(name = "created_at", nullable = false) private LocalDateTime createdAt;
    @Column(name = "updated_at", nullable = false) private LocalDateTime updatedAt;
    @PrePersist void pp() { createdAt = updatedAt = LocalDateTime.now(); }
    @PreUpdate void pu() { updatedAt = LocalDateTime.now(); }
}

## §8 风险对策

- **CSV 中文乱码**：UTF-8 BOM 头（\uFEFF）＋`filename*=UTF-8''`——finance 七端点已验证 Excel/WPS 双击直开。
- **overview() 性能**：六块聚合各服务内查询，导出与页面同源同代价；营销域数据量级小（券/活动/推送/海报/直播/短视频单店数百行级），同步导出无超时风险；若日后量级增长再切 ReportJob 异步链（基建已备）。
- **Job 重复触达**：idemKey UK＋last_sent_week 双防重；多实例/重启同周重跑幂等。
- **跨服务调用失败**：LevelDowngradeNotifier 全软降级先例（try/catch 单条容错＋失败计数入 RUN 审计），不阻塞营销主链路。
- **权限矩阵漂移**：marketing:export 已生成在案（gen_perm_matrix.mjs 产物勿手改）；仅引用不新增，零矩阵改动。
