## §2 建模（V51 DDL）

```sql
-- V51__marketing_content_deal_backfill.sql（marketing-service，幂等可重入）

-- ① 短视频上下架状态列（存量行 DEFAULT 回填 PUBLISHED）
ALTER TABLE short_video ADD COLUMN IF NOT EXISTS status VARCHAR(12) NOT NULL DEFAULT 'PUBLISHED';
ALTER TABLE short_video DROP CONSTRAINT IF EXISTS chk_short_video_status;
ALTER TABLE short_video ADD CONSTRAINT chk_short_video_status CHECK (status IN ('PUBLISHED','OFFLINE'));

-- ② 成交归属登记表（幂等锚 order_no；POSTER 词表预留，本期无写入方）
CREATE TABLE IF NOT EXISTS mkt_deal_attribution (
    id           BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    order_no     VARCHAR(40)  NOT NULL,
    source_type  VARCHAR(16)  NOT NULL,
    source_id    VARCHAR(24)  NOT NULL,
    amount       BIGINT       NOT NULL,            -- 成交额（分），以 paid-orders 快照为准
    status       VARCHAR(10)  NOT NULL DEFAULT 'PAID',
    paid_at      TIMESTAMPTZ  NOT NULL,
    refunded_at  TIMESTAMPTZ,
    created_at   TIMESTAMPTZ  NOT NULL DEFAULT now(),
    updated_at   TIMESTAMPTZ  NOT NULL DEFAULT now(),
    CONSTRAINT uk_mkt_deal_attr_order   UNIQUE (order_no),
    CONSTRAINT chk_mkt_deal_attr_type   CHECK (source_type IN ('LIVE_SESSION','SHORT_VIDEO','POSTER')),
    CONSTRAINT chk_mkt_deal_attr_status CHECK (status IN ('PAID','REFUNDED'))
);
CREATE INDEX IF NOT EXISTS idx_mkt_deal_attr_source ON mkt_deal_attribution (source_type, source_id);

-- ③ 回写游标（单行，镜像 auto_grant_state；NULL→首轮 2000-01-01 全量回填）
CREATE TABLE IF NOT EXISTS deal_backfill_state (
    id               SMALLINT PRIMARY KEY,
    last_paid_at     TIMESTAMPTZ,
    last_refunded_at TIMESTAMPTZ,
    CONSTRAINT chk_deal_backfill_single CHECK (id = 1)
);
INSERT INTO deal_backfill_state (id) VALUES (1) ON CONFLICT (id) DO NOTHING;
```

txn 侧（**无迁移**，ddl-auto: update 实体驱动自动加列）：`TxnOrder` 加 `sourceType`（source_type VARCHAR(32) 可空）＋`sourceId`（source_id VARCHAR(64) 可空）。

### 3.1 marketing-service（/api/marketing 前缀，类级 marketing:view 兜底）
| 方法 | 路径 | 权限 | 语义 |
|------|------|------|------|

| GET | /posters | 同上 | 不变 |
| GET | /live-sessions | marketing:view **OR live:view**（D7） | 不变 |

| POST | /short-videos | live:edit | 发布：videoId 随 LiveService 单号惯例（SV 前缀）；title 违禁词校验（复用 ForbiddenWordService）；platform 词表 400 中文；tags JSON 数组校验；plays/likes/dealCount/dealAmount=0、status=PUBLISHED、publishedAt=当日；审计 SHORT_VIDEO/CREATE |
| PUT | /short-videos/{id} | live:edit | 编辑 title/platform/tags（其余列服务端忽略防刷数据）；404/违禁词/词表同发布；审计 SHORT_VIDEO/UPDATE |
| POST | /short-videos/{id}/toggle | live:edit | PUBLISHED⇄OFFLINE 幂等翻转（重复同态 changed=false，live toggle 先例）；审计 SHORT_VIDEO/TOGGLE（仅实际翻转） |

### 3.2 txn-service
- POST /api/txn/card-order、POST /api/txn/retail-order：cmd 加可选 `sourceType`（NONE|LIVE_SESSION|SHORT_VIDEO，缺省 NONE）、`sourceId`（sourceType 非 NONE 时必填，400「来源标识必填」中文）；非法词表 400；落库映射两列。
- GET /api/txn/internal/paid-orders：PaidOrderView 七→九字段（+sourceType/sourceId，可空，internal 消费方向后兼容）。

### 3.3 DealBackfillJob（marketing-service，AutoGrantJob 范式）
- @Scheduled fixedDelay=300_000 initialDelay=45_000；每节拍两段：paid 段→refund 段；分段游标，段成功才推进对应游标（故障不推进）。
- paid 段：窗口 (last_paid_at, now] 拉 paid-orders → 过滤 sourceType∈{LIVE_SESSION,SHORT_VIDEO} → 逐单 INSERT mkt_deal_attribution（order_no 冲突＝已处理跳过）→ 成功插入才 `UPDATE live_session|short_video SET deal_count=deal_count+1, deal_amount=deal_amount+:amt WHERE :sid`（source_id 不存在→跳过计入 skipped）；窗口右闭取 max(createdAt) 推进。
- refund 段：窗口 (last_refunded_at, now] 拉 refunded-orders → 命中 attribution.status=PAID → 置 REFUNDED＋refunded_at＋负向增量（deal_count-1、deal_amount-=amount，floor 0 保护）；未命中跳过。
- 任一段有产出才落一条 SYSTEM 汇总审计（DEAL_BACKFILL/RUN，payload 含双段计数与游标窗口）；TxnServiceUnavailableException 软降级本拍放弃不推进。
