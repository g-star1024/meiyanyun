## §6 竞品调研摘要（按用户「做好竞品调研选择最合适的」授权）

虽本批零施工，按用户授权对营销域后续方向做简要竞品调研登记，供后续批次参考：

| 方向 | 竞品参考 | 推荐选型 | 理由 |
|---|---|---|---|
| 素材库文件存储 | 有赞美选云/美呗（阿里云 OSS） | MinIO 自建优先（私有化部署兼容） | 医美连锁 B 端 SaaS 私有化场景多，MinIO S3 兼容 API 可无缝切阿里云 OSS；初期不施工，留接口 |
| 海报渲染 | 有赞美选云（服务端 Puppeteer）/ 美呗（前端 Canvas + html2canvas） | 服务端 Puppeteer（headless Chrome） | 模板复杂度高（二维码+推荐人+门店信息合成），前端 Canvas 兼容性差；Puppeteer 渲染精度高、可复用 AI 中心已有 Chromium 基础设施 |
| 营销归因 | 有赞美选云（末次触点）/ 美呗（首次+末次双模型） | 末次触点归因（Last Touch） | 医美行业决策链长（3-6 个月），首次触点数据噪声大；末次触点最易实现且 ROI 可解释性强；多触点加权需事件流前置，当前触点数据未采集 |
| 公海客户 | 有赞美选云（30 天未跟进自动回公海）/ 美呗（7 天+手动回收双机制） | 30 天未跟进自动回公海 + 手动回收 | 医美客户跟进周期长于快消，30 天为行业通行阈值；手动回收兜底防止优质客户误回 |
| 客诉管理 | 有赞美选云（工单+审批+SLA）/ 美呗（工单+赔偿+回访闭环） | 工单+审批+SLA+回访闭环 | 医美客诉涉及医疗安全，需赔偿审批与回访闭环；可复用既有 ApprovalService 审批引擎 |
| 私域自动化 Flow | 有赞美选云（简单触发器）/ 美呗（可视化 Flow 编排） | 简单触发器先行（术后 N 天关怀/沉睡 60 天唤醒/复诊到期召回） | 可视化 Flow 编排引擎成本高、使用频率低；三个高频场景硬编码触发器即可覆盖 80% 需求 |
